# OWCA v0.7.1 Compact Creation Loadout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make equipment in the Create Character Loadout stage display only a resolved name and meaningful quantity while preserving the actions needed to search, add, and remove equipment.

**Architecture:** Keep the existing shared `CharacterInventoryEditor` and its explicit creation/maintenance presentation modes. Narrow only the creation render path: compact owned-item labels, name-only selector entries, and no selected-definition detail panel. Maintenance mode continues to use the complete catalogue definitions and detailed editor without state, calculation, persistence, or schema changes.

**Tech Stack:** Godot 4.7, typed GDScript, the existing SceneTree UI regression tests, and real-renderer responsive capture checks.

## Global Constraints

- Change only the Loadout stage embedded in Create Character.
- Preserve Manage Loadout, Armoury, JSON state, calculations, finalization, reconciliation, and dossier behavior.
- Retain Search, category filtering, item selection, **Add Equipment**, and optional-item removal.
- Display a single item as `Lasgun` and a stack as `4x Charge Pack`.
- Do not display creation-mode item profiles, source, availability, weight, armour values, or repeated origin labels.
- Keep the application at `0.7.1-dev`; record the change under Unreleased.
- Preserve usability at 960x650 without horizontal scrolling.
- Do not stage the user's local `project.godot`, `export_presets.cfg`, `addons/`, or `godot-ai-LICENSE.txt` changes from the normal checkout.

- [ ] **Step 3: Add one compact creation-label helper**

In `OWCA/ui/character_inventory_editor.gd`, add:

```gdscript
func _creation_item_label(owned: Dictionary, resolved: Dictionary) -> String:
	var name := str(resolved.get("name", owned.get("definition_id", "Item")))
	var quantity := int(owned.get("quantity", 1))
	if quantity > 1:
		return "%dx %s" % [quantity, name]
	return name
```

Use this helper for both starting equipment and optional additions. Remove the creation-only calls to `_creation_item_profile()` and remove the repeated `STARTING EQUIPMENT` and `OPTIONAL ADDITION` labels. Keep `CreationOptionalRemoveButton` unchanged.

- [ ] **Step 4: Make the optional-equipment chooser compact only in creation mode**

In `_build_catalogue_add_controls()`, create and add `catalogue_details` only when `presentation_mode == MODE_MAINTENANCE`; set it to `null` in creation mode before refreshing matches.

In `_refresh_catalogue_matches()`, choose selector text by mode:

```gdscript
var selector_text := str(item.get("name", item.get("id", "Item")))
if presentation_mode == MODE_MAINTENANCE:
	selector_text = "%s  [%s]" % [
		selector_text,
		str(item.get("category", "")).replace("_", " ").capitalize()
	]
catalogue_selector.add_item(selector_text)
```

Leave `_render_catalogue_details()` and its complete maintenance output intact; its existing null guard makes creation mode a no-op.
